# ICLR 2027 submission checklist

## Repository-verified

- [x] Official `iclr2027_conference.sty` and bibliography style are used.
- [x] Review mode is enabled; `\iclrfinalcopy` remains disabled.
- [x] The manuscript author block is anonymous.
- [x] References precede the appendix in the same PDF.
- [x] The mandatory AI use statement is present.
- [x] Reproducibility material is referenced from the main paper.
- [x] AIFS ENS is evaluated through its ensemble mean only; the paper makes no
  probabilistic-calibration claim.
- [x] Score-based figures and tables regenerate from checked aggregate inputs.
- [x] The PDF builds with Tectonic 0.16.9.

## Recheck after the final build

- [x] Main text ends by page 9.
- [x] No unresolved references, missing citations, or overfull boxes remain.
- [x] Figures and tables are legible at 100% zoom.
- [x] The PDF body and metadata are anonymous; prior work is cited only in the
  third person as permitted by ICLR.
- [x] The OpenReview title and abstract match the submitted PDF.
- [x] The anonymous code archive contains no Git history, account names,
  company email addresses, or identifying repository URLs.

## Author actions in OpenReview

- [ ] Paste the final genuine abstract from `paper/openreview_abstract.txt`.
- [ ] Confirm the complete author list; no author can be added after the
  abstract deadline.
- [ ] Confirm every author has an up-to-date OpenReview profile and that the
  submission email is linked to that profile.
- [ ] Confirm no author exceeds the 20-paper co-authorship quota.
- [ ] Confirm the reciprocal-reviewing requirement is satisfied and at least
  one eligible author registers to review three papers.
- [ ] Complete the AI-use fields consistently with the manuscript statement.
- [ ] Read and acknowledge the ICLR Code of Ethics and Code of Conduct.
- [ ] Confirm the work is not under review at another archival venue.
- [ ] Upload the final PDF and supplementary archive before
  25 September 2026, 11:59 PM AOE.
